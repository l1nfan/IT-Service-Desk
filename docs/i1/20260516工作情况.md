## 四、当前已完成的工作内容

### 4.1 后端（itsm-ticket 模块）

1. **Domain层**：`ItTicket`、`ItTicketCategory`、`ItTicketAttachment`、`ItTicketLog` 四个实体类
2. **Mapper层**：四张表的 MyBatis XML 映射，工单表含关联查询（JOIN分类+用户），附件表含逻辑删除
3. **Service层**：
   - `ItTicketServiceImpl`：CRUD + 编号生成 + 审批 + 分配 + 通用流转 + 可用转换查询 + **操作日志记录**
   - `ItTicketCategoryServiceImpl`：CRUD + 树形构建 + 唯一性校验 + 子分类检测 + 祖级更新
   - `ItTicketAttachmentServiceImpl`：按ID查询 + 按工单查询 + 新增 + 删除
   - `ItTicketLogServiceImpl`：按工单查询 + 列表查询 + 新增日志
4. **Controller层**：
   - `ItTicketController`（11个接口：CRUD + 导出 + 审批 + 分配 + 流转 + 可用转换 + **操作日志查询**）
   - `ItTicketCategoryController`（5个接口：CRUD + 树形构建）
   - `ItTicketAttachmentController`（4个接口：**上传 + 下载 + 列表 + 删除**）
5. **状态机**：`TicketStatus`(10种状态) + `TicketTransition`(15种转换规则) + `TicketStateMachine`(校验组件)
6. **逻辑删除**：工单、分类、附件删除均已改为 `del_flag='2'`
7. **操作日志**：创建/编辑/删除/审批/分配/流转操作均自动记录日志（含操作人、原状态、目标状态、备注）

### 4.2 前端（itsm-ui）

1. **API封装**：`ticket.js`（12个接口：CRUD + 审批 + 分配 + 流转 + 可用转换 + **附件列表 + 附件删除 + 日志查询**）、`category.js`（5个接口：CRUD）
2. **工单管理页面** (`views/itsm/ticket/index.vue`)：
   - 搜索表单：工单编号/标题/分类(树形选择)/优先级/状态/创建时间范围
   - 操作按钮：新增/修改/删除/导出
   - 数据表格：编号/标题(可点击跳转详情页)/分类/优先级/状态/创建人/处理人/创建时间/操作
   - 条件操作：SUBMITTED状态显示审批按钮，APPROVED状态显示分配按钮
   - 新增/编辑对话框：标题/分类/优先级/影响范围/期望解决时间/描述/备注/**附件上传**
   - 详情对话框：el-descriptions展示完整信息
   - 审批对话框：通过/驳回 + 审批意见
   - 分配对话框：用户选择 + 备注
3. **工单详情独立页面** (`views/itsm/ticket/detail.vue`) — **本次新增**：
   - 基本信息卡片：el-descriptions展示工单完整信息 + 审批/分配/流转操作按钮
   - 附件管理Tab：上传/下载/删除附件，含文件大小格式化展示
   - 操作日志Tab：el-timeline时间线展示操作记录，含状态变更标注
   - 流转记录Tab：el-table表格展示状态流转历史，含字典标签渲染
4. **分类管理页面** (`views/itsm/category/index.vue`)：
   - 树形表格展示，支持展开/折叠
   - 搜索：分类名称/状态
   - CRUD操作：新增(含子分类)/修改/删除
5. **路由配置**：动态路由中新增 `/itsm/ticket/detail` 详情页路由，权限标识 `itsm:ticket:query`

### 4.3 数据库

1. **4张核心表**：`it_ticket`、`it_ticket_category`、`it_ticket_attachment`、`it_ticket_log`
2. **菜单权限**：IT运维工单(一级) > 仪表盘/工单管理/工单分类(二级) + 按钮权限(含审批/分配)
